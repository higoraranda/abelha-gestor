# Abelha na Cloudfy — plano de implementação

**Objetivo:** criar sete workflows revisáveis e desativados na instância existente socialbaboon, sem tocar dados comerciais ou produção do Abelha.

**Spec:** pedido anexado de 12/11/2026; arquitetura e auditoria de ativação existentes.

**Arquitetura:** n8n orquestra, backend valida/isola/persiste. Um único agendador de tick cobre finanças, contas, revisão e push. Auxiliares de contas/revisão não têm agendamento próprio. Captura usa webhook autenticado e classificação determinística explícita; busca passa por Overpass no backend e grava candidatos pendentes. Projetos aceita relatório autenticado e encaminha bytes GitHub originais para validação HMAC. Preços usa contrato JSON de API HTTPS escolhida pelo operador, sem scraping nem cotações artificiais.

**Decisões do implementador:** continuar inline neste checkout alterado, sem worktree/commit; não há necessidade de uma escolha nova de plataforma. Reutilizar somente estrutura de modelos, nunca credenciais de outros projetos. Entrada webhook é a fonte funcional comum para email/formulário; IMAP/serviço de email é opcional e manual. Nenhum LLM ou serviço pago é necessário para a classificação inicial. HTTP falha de forma explícita e usa repetição limitada apenas em mutações idempotentes; não continuar em erro.
